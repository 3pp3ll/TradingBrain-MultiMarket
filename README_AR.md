# Trading Brain — Options Intelligence Add-on (مرحلة القراءة)

هذه إضافة **مستقلة داخل مشروع قائم**: لا تعدّل أو تحذف ملفات MT5، ولا تتصل بDeriv أو الوسطاء، ولا تُرسل أوامر تداول.

## فحص سريع في VS Code على Windows

1. انسخ مجلد `options_intelligence` إلى **جذر مشروع TradingBrain_Deriv الحالي** بعد أخذ نسخة احتياطية. لا تنقل/تمسح ملفات المشروع الحالية.
2. انسخ `samples` و`tests` إلى جذر المشروع نفسه.
3. افتح Terminal داخل جذر المشروع وشغّل:

```powershell
python -m unittest discover -s tests -v
python -m options_intelligence.scanner --input samples/example_finviz_normalized.csv --output outputs/options_signals.json --as-of-utc 2026-11-10T16:00:00Z
```

هذه البيانات **افتراضية للتأكد من سلامة التشغيل فقط**؛ ليست أسعار السوق ولا نتائج تداول. سيتم إنشاء `outputs/options_signals.json` يتضمن مرشحات وقرارات رفض وأسبابها، دون أي تنفيذ.

## بيانات Finviz الفعلية

لا توجد في هذه النسخة خاصية scraping ولا التفاف على حدود وصول الموقع. احصل على تصدير CSV من Finviz Elite إن كان لديك حق استخدامه؛ ثم طابق أسماء الأعمدة المحلية مع الصيغة أدناه، ويمكن لاحقاً بناء محول ثابت للأعمدة بعد أن نرى رؤوس ملف تصدير حقيقي **بدون بيانات حساب أو مفاتيح**.

الأعمدة الإلزامية:

`ticker,market_cap,average_volume,relative_volume,rsi,sma20,sma50,sma200,optionable,snapshot_utc,earnings_date`

- `snapshot_utc`: تاريخ/وقت مصدر البيانات بصيغة ISO8601 دقيقة ومنطقة UTC، وليس وقت نسخ الملف.
- `earnings_date`: تاريخ موثّق بصيغة YYYY-MM-DD؛ المجهول يُرفض افتراضياً.
- `sma20, sma50, sma200`: قيم المتوسطات **بالسعر**؛ إن كانت في التصدير نسباً مئوية أو قيم مقارنة بالسعر، يجب تحويلها بشكل صحيح قبل الاستعمال. لا تضع أرقاماً تخمينية.
- `market_cap` يقبل `B/M/T` و`average_volume` يقبل `M`؛ `relative_volume` رقم نسبي.
- الفحص المبدئي يرفض أي صورة بيانات أقدم من 36 ساعة. وقت العطلات/إغلاق السوق يستلزم تكييف حد الحداثة بحذر، وتظل البيانات غير صالحة للتنفيذ.
- المخرجات تصف اتجاه **السهم** فقط، وليس سعراً أو قراراً لشراء عقد أوبشن؛ لا تتضمن سلسلة الخيارات وStrike/Expiry/Bid/Ask/Greeks.

## لماذا لم نربط الداشبورد القديم الآن؟

الداشبورد السابق يخزن `expert_brain_v2_local_2026` داخل localStorage وينتظر صفقات قصيرة المدة بعملة الريال، وليس عقود خيارات أسهم أمريكية بعملة الدولار، لذلك لا نخلط سجلاتها أو نحقنها بدون مخطط ترحيل ونسخة احتياطية.

ملف الإضافة الأول: `options_intelligence/scanner.py`. إن توفر كود المشروع المحلي الأصلي، يفضل دمج هذه الوحدة في المجلد الصحيح بعد فحصه.

## حدود المخاطر المعتمدة للمرحلة القادمة

1% من رأس المال الأساسي بعد الخسائر، 3% خسارة يومية، خسارتان متتاليتان، دون Martingale. ليست هذه الوحدة منفذاً للأوامر، وبالتالي لا تدّعي تطبيق تلك الحدود على وسيط حقيقي. يجب برمجة بوابة المخاطر المشتركة قبل أي ربط تداول.
